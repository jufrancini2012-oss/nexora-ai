# Roadmap Autônomo

## Fase 1 — núcleo (agora)
1. Política de autonomia
2. Orquestrador por eventos
3. Auditoria de decisões
4. Banco de dados comercial/financeiro
5. Painel mobile de controle

## Fase 2 — operação real
1. Gateway de pagamento
2. Webhooks assinados + idempotência
3. Catálogo/fonte de produtos autorizada
4. Mensageria e follow-up
5. Domínio/HTTPS

## Fase 3 — aprendizado
1. métricas por funil
2. testes controlados
3. atualização do score
4. substituição automática de oportunidades fracas
5. relatórios e alertas

## Regra
O sistema começa em sandbox. A passagem para dinheiro real só ocorre após configurar credenciais e limites, sem guardar senha bancária e sem permitir que o modelo altere o destino do dinheiro.
