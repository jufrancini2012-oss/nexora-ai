# API — Robo Vendas AI

Worker-compatible MVP API. Current version runs in sandbox/demo mode and deliberately does not connect to real payment providers or bank accounts.

Endpoints:
- GET /api/health
- GET /api/dashboard
- GET /api/products
- GET /api/autonomy
- GET /api/finance
- POST /api/events

Install Wrangler and configure Cloudflare only when the deployment step begins. No banking credentials are stored in this codebase.
